🔍 HOW IT WORKS NOW:

Request Flow:
├─ Browser requests /assets/css/style.css
│  └─ router.php detects .css extension
│     └─ Checks file exists
│        └─ Returns false to dev server
│           └─ Dev server serves file directly ✅

├─ Browser requests /tours
│  └─ router.php checks it's not a static file
│     └─ Maps /tours to tours.php
│        └─ Loads and executes tours.php ✅

├─ Browser requests /assets/images/tour.jpg
│  └─ router.php detects .jpg extension
│     └─ Checks file exists
│        └─ Returns false to dev server
│           └─ Dev server serves image directly ✅
