🔧 DROPDOWN FIX DETAILS:

Old Style:
   background-image: url("data:image/svg+xml,...");
   width: 12px; height: 12px;  ← Too small, hard to see
   padding-right: 36px;

New Style:
   background-image: url("data:image/svg+xml,...");
   width: 14px; height: 14px;  ← Clearer, more visible
   background-size: 14px;       ← Proper scaling
   padding-right: 40px;         ← More space for icon
   stroke='%237b5cbf'          ← Purple color matching design
   stroke-width='1.5'          ← Proper line thickness
   stroke-linecap='round'      ← Smooth edges
   stroke-linejoin='round'     ← Professional look

High-DPI Support:
   @media (-webkit-min-device-pixel-ratio: 1.5)
   background-size: 16px;  ← Larger on Retina displays
